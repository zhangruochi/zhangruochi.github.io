DIGITAL TWIN LAB / A MIND IN THE MAKING

让研究进化。
让进化本身进化。

我正在打造一个多肽科研数字孪生体：用 harness 承载经验、知识、方法和判断，使 Agent 既能改进多肽设计，也能改进自己的科研系统。

愿景 + 实现中的系统

MY THESIS / INTELLIGENCE BEFORE A DATA FLYWHEEL

科学数据积累很慢。智能的积累，不必等待。

AI4S 的实验数据飞轮，短期内常被实验周期、成本与反馈稀疏所限制。我的思路是先推动智能飞轮：让每个问题、每次失败、每项审查，成为下一次研究更好的起点。

长期目标是 human-out-of-loop：人明确目标与边界，Agent 自主推进研究。重点不是再造一个 GUI，而是可调用、可组合、可验证的 skills，以及让它们可靠工作的 harness。当前系统仍保留独立审查与发布权限边界；目标不等于已实现的自主闭环。

RSI / TWO CONNECTED LOOPS

两条循环，互为研究对象。

RSI：递归自我改进。改进科研能力，也改进产生改进的机制。

科研循环↻

更好的多肽设计

  1. 明确科学问题与可检验目标
  2. 设计 / 预测 / 分析候选
  3. 用对照与适用范围评价证据
  4. 保留结果、失败与待验证假设

↺ 有依据地修订下一次设计

⇄失败 → 缺口
改进 → 新方法
HARNESS LOOP↻

更好的科研系统

  1. 编译研究轨迹与经验
  2. 蒸馏知识，诊断能力缺口
  3. 提出 skills / 工具 / 策略改进
  4. 冻结评测，独立审查并采纳或回滚

↺ 连评估与优化机制，也接受检验

因果连接：科研失败提出能力缺口 → harness 生成修复候选 → 独立评测检验改进 → 已验证的方法返回科研循环。评估器本身的改动也必须接受独立检验，不能自己给自己授权。

COGNITIVE SYSTEM / FIVE FUNCTIONS

大脑的五个相互连接的部分。

这是功能分解，不是五个固定角色在表演。确定性代码处理证据，Agent 承担判断。

01 / Experience compiler

经验编译器

任务轨迹 → 有来源的事实与失败记录。

实现：经验采集与投影。完整长期收益尚未实测。

02 / Knowledge distillation

知识蒸馏

事实 → 可检索知识、skills 与候选规则。

源码已查看：类型化资产与知识沉淀路径。效果需要逐项运行证据。

03 / Metacognition

元认知

证据与失败 → 能力边界、缺口和策略诊断。

实现：Self-Model 与诊断。低证据能力保持未知。

04 / Harness optimizer

Harness 优化器

诊断 → 隔离的工具、skills、工作流改进候选。

实现：候选与回归评估路径；改进不能自行授权合并。

05 / Evaluator

评估器

候选 + 冻结用例 → 可追溯评估、拒绝或回滚。

实现：评估与证据门；自主可信合并仍待验证。
