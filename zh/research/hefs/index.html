HeFS: Helper-Enhanced Feature Selection via Pareto-Optimized Genetic Search

通过 Pareto 优化的遗传搜索，用互补 helper 特征增强特征选择。

01 / 研究问题

既有方法选出的特征子集，可能遗漏被丢弃特征中的互补信息。

02 / 创新思路

结合有偏初始化、比例引导变异和 Pareto 优化遗传搜索，寻找互补的 helper 特征集合。

03 / 方法机制

HeFS 保留既有特征子集，在剩余空间寻找互补 helper；有偏初始化、比例引导变异及 Pareto 选择共同优化准确率和特征互补性。

04 / 实验设置

作者稿 v1 的 Table 1 列出 18 个数据集，其他位置总数表述不一致。§4.2 使用十次随机运行、五折验证，k=5 近邻评估器，种群 30、100 代。基线含 RF/Lasso 与六种进化选择器。GSE64951 含 94 样本/54,675 特征；DLBCL 为 77/5,469。

05 / 主结果

Table 2 中，DLBCL 的 BHOA 准确率从 97.50% 提升至 99.88%，但 Semeion 的 FTGGA 从 97.80% 降至 96.62%。

06 / 消融与局限

Figure 3 将初始化/变异机制替换为随机变体。收益依赖原选择器、数据集和特征扩张；小样本高维队列及未明确嵌套的搜索/验证限制泛化解释，特征互补不等于生物因果。这些是预印本实验，与正式版分开。

特征选择是通用方法，并非多肽专属结果。论文于 2026 年在线优先发表，卷期尚待确定。
