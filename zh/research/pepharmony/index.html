01 / 研究问题

多肽结构复杂又灵活。能否借助结构信息，让模型更好地理解序列？

02 / 创新思路

通过多视图对比学习对齐序列与结构表征，将结构信息迁移到序列编码器。

03 / 方法机制

ESM 序列编码器与 GearNet 结构编码器通过对比训练对齐，下游预测保留纯序列输入；VAE 变体另探索生成式学习。

04 / 实验设置

作者稿 v1 收集 17,300 条短于 50 残基的 PDB 多肽及 AlphaFold 结构，并以结构置信度过滤子集进行预训练。CPP 含 1,162 正例和 1,162 负例，PROSO-II 用于溶解度；基线包括 ESM2、微调 ESM 和 GearNet。所读正文未提供下游精确划分比例。

05 / 主结果

Table 1 的 CPP AUC 为 0.874，ESM2 为 0.864；亲和力 Spearman 为 0.447，低于微调 ESM 的 0.473。不以 2026 正式期刊结果替代这些 v1 数值。

ORIGINAL FIGURE / PAPER SOURCE

方法如何工作。

训练时，ESM 序列编码器与 GearNet 结构编码器学习对齐；推理时，下游任务只使用序列编码器。结构知识通过训练进入表征，不需要每个推理样本都输入结构。

A BOUNDED CASE / REPRESENTATIONS IN CONTEXT

回到具体的多肽问题。

结构信息能否改善序列表征？

CPP 是稿中一个具体检验：训练时加入序列–结构对齐，下游推理保持序列输入。CPP AUC 的同稿比较支持这一任务上的收益；亲和力任务的反例提醒我们收益依赖任务。

这是公开任务案例，不是某个实验候选的治疗效果。

06 / 消融与局限

Table 3 中，CPP AUC 从未按置信度排序的 0.843 提高至排序后的 0.874；diffusion 初始化为 0.855。预测结构置信度与短肽柔性影响表征；早期亲和力/溶解度表有不一致，排除有争议的项。对比对齐并不证明结构理解全面更强。

所链接作者稿为早期版本，上方列出最终期刊信息。表征基准并不能证明治疗疗效或实际部署。
