PepDDG.

通过信息通道分解预测多肽–蛋白质结合的 ΔΔG。

NeurIPS 2026

会议官方列表 ↗

01 / 要解决的问题

按单点多肽突变对蛋白结合的影响排序。

02 / 核心新意

将能量扰动、几何环境和进化兼容性等权排序融合；残差校准版单独报告。

思路如何运转

03 / 公开证据说明了什么

本人授权的 V4 在 332 个 peptide-chain 突变、33 个 target 的晶体结构基准上报告：零样本 PepDDG pooled Spearman 0.619，PepDDG-Cal 0.691。会议列表核实题目，接收状态由本人确认。

会议列表核对: PepDDG ↗

04 / 结论的边界

输出排序，不是绝对 kcal/mol 误差。仅单点替换；稳定化突变和不准确结合 pose 是重要失效场景。不声称 V4 为最终 camera-ready，也不推断个人作者角色。

此处是本站对证据范围的编辑说明，并非未经核实的作者原话。

AUTHOR-AUTHORIZED V4 / ORIGINAL FIGURE 1

三种证据，同一个排序问题。

PepDDG 将能量扰动、几何环境和进化兼容性转换到排序空间，以等权 Borda rank-sum 融合。较大的分数表示更可能削弱结合；输出是突变顺序，不是经过校准的 kcal/mol 预测。

01 / 能量扰动

OpenMM、Amber ff14SB / OBC2，以配对 wild-type / mutant 重启构建结合能代理和界面交互代理。

02 / 几何环境

wild-type 结构中的重原子链间接触（8 Å）与 Cα 邻居（10 Å）。只依赖位置，不能区分同一位置的不同替换。

03 / 进化兼容性

预训练 ProteinMPNN 的 complex / isolated-chain 条件似然差与突变似然比。无任务特定微调；预训练模型本身来自学习。

部署时在同一 target 的候选间排序；主论文 pooled benchmark 在完整 cohort 内排序。训练免除指没有任务特定训练或学习融合权重，不表示使用的基础模型没有预训练。

DATA / CRYSTAL-STRUCTURE BENCHMARK

332 个突变，33 个 target。

PepDDG-Bench 来自 SKEMPI v2：单点、peptide-chain 突变，一方长度为 5–80 个残基；排除超短链、饱和突变占主导的 target 与结构准备失败。主基准输入为对应 PDB 晶体结构。实验 ΔΔG > 0 表示结合去稳定化。

V4 §3、§6.1、Table 1（第 3、7 页）。指标为 pooled Spearman ρ；95% CI 使用 target-stratified bootstrap。以下是作者稿报告值，不是本网站工作的独立复现。

ABLATION / WHAT THE CHANNELS CONTRIBUTE

互补，比重复更有信息。

跨通道消融

单通道 ρ 为 0.469–0.504；双通道组合为 0.568–0.574；三个通道为 0.619。通道间相关为 0.33、0.40、0.41，相关较低不等于统计独立。

V4 Figure 2 · pp. 7–8 · N=332

增加信号并非总有收益

能量通道界面代理单独为 0.477，完整 binding proxy 为 0.316，两者 rank-sum 为 0.473。可选第四个 alanine 通道只在 N=303 的覆盖子集上由 0.633 到 0.637，不能与 N=332 的 0.619 直接比较。

V4 Appendix Table 9 · p. 23; Figure 2

理论分析依赖给定的 rank-covariance 条件，不保证任意通道融合都提高效果。

BOUNDED DIAGNOSTICS / STRUCTURE INPUTS

强结果，要带着边界一起看。

短肽与环肽

短肽（<20 residues）：ρ=0.813，CI [0.684, 0.909]，47 mutations / 5 targets。环肽：ρ=0.872，CI [0.753, 0.926]，35 mutations / 4 targets。

这是保留的回顾性诊断 cohort；不是前瞻性发现。4 个环肽 target 的精确 sign-flip 检验最小 p=0.0625，不能声称 p<0.05。

V4 Table 3 · p. 9; Appendix C.9 · p. 23

预测结构是单独诊断

在匹配的 109 个突变中，Boltz-2 predicted-input ρ=0.621，crystal-input ρ=0.592。该 cohort 与主基准 332 个不同，不能解释为预测结构普遍优于晶体。

使用最高 ipTM 的 wild-type sample，未微调结构预测器。较大的 pose 错误和突变引发的 binding-mode 改变未被显式建模。
