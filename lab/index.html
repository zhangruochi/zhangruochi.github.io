DIGITAL TWIN LAB / A MIND IN THE MAKING

Evolve the research.
Evolve how it evolves.

I’m building a digital twin for peptide research: a harness that holds experience, knowledge, methods and judgment, so agents can improve peptide design and their own research system.

Vision + a system under construction

MY THESIS / INTELLIGENCE BEFORE A DATA FLYWHEEL

Scientific data accumulates slowly. Intelligence need not wait.

In AI4S, experimental cycles, cost and sparse feedback can slow the data flywheel. My approach is to build an intelligence flywheel first: turn each question, failure and review into a better starting point for the next investigation.

The long-term goal is human-out-of-loop: people define goals and boundaries; agents carry the research forward. The focus is callable, composable, verifiable skills and the harness that makes them reliable. Current integration and release still have independent review and permission boundaries; the goal is not a claim of an achieved autonomous loop.

RSI / TWO CONNECTED LOOPS

Two loops. Each studies the other.

RSI: recursive self-improvement. Improve research capability, and the mechanism that produces improvements.

RESEARCH LOOP↻

Better peptide design

  1. Define a scientific question and testable goal
  2. Design / predict / analyze candidates
  3. Evaluate evidence with controls and scope
  4. Retain outcomes, failures and open hypotheses

↺ Revise the next design from evidence

⇄Failures → gaps
Improvements → methods
HARNESS LOOP↻

Better research systems

  1. Compile research trajectories and experience
  2. Distill knowledge and diagnose capability gaps
  3. Propose skill / tool / strategy improvements
  4. Freeze evaluation; review, adopt or roll back

↺ Evaluate the evaluator and optimizer too

Causal link: research failures expose gaps → the harness proposes repairs → independent evaluation tests the improvement → verified methods return to research. Changes to the evaluator itself require independent checks; it cannot authorize itself.
